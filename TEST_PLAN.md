# Тест-план и чек-листы — pw-saucedemo

Проект: E2E-тестирование сайта [saucedemo.com](https://www.saucedemo.com/)
Стек автоматизации: Playwright + TypeScript, Page Object Model

## 1. Введение

Документ описывает подход к тестированию демонстрационного интернет-магазина saucedemo.com и содержит чек-листы для функциональных областей, покрытых автотестами этого репозитория.

Цель проекта — показать полный цикл тестирования: от анализа требований и составления чек-листов до реализации автотестов на Playwright + TypeScript с использованием Page Object Model.

**Объект тестирования**

| Параметр | Значение |
|---|---|
| Приложение | https://www.saucedemo.com/ |
| Тип приложения | Демонстрационный e-commerce (SPA) |
| Тестовые учётные данные | `standard_user` / `secret_sauce` |

## 2. Область тестирования (Scope)

**In scope**
- Авторизация (успешный вход, вход с неверными данными)
- Каталог товаров: добавление и удаление товара из корзины
- Корзина: отображение добавленных товаров, переход к оформлению заказа
- Оформление заказа (checkout): заполнение данных покупателя, подтверждение заказа

**Out of scope**
- Нагрузочное и производительное тестирование
- Тестирование безопасности (SQLi, XSS и т.д.)
- Кроссбраузерное тестирование (текущая версия — только Chromium)
- Мобильная адаптивность / responsive-вёрстка
- Тестирование сортировки товаров и второстепенных страниц (About, Reset App State)

## 3. Стратегия тестирования

| Параметр | Значение |
|---|---|
| Уровень тестирования | UI / E2E (сквозные сценарии через интерфейс) |
| Вид тестирования | Функциональное, позитивные и негативные сценарии |
| Инструменты | Playwright + TypeScript |
| Паттерн | Page Object Model (`pages/*.ts`) |
| Браузер | Chromium (Desktop) |
| Отчётность | Встроенный HTML-репортер Playwright |

## 4. Критерии входа и выхода

**Вход:** окружение развёрнуто, сайт доступен, чек-листы согласованы.
**Выход:** все пункты чек-листов пройдены (вручную или автотестом), все автотесты зелёные, незакрытые дефекты зафиксированы отдельно.

## 5. Риски

| Риск | Митигация |
|---|---|
| Изменение локаторов на сайте (`data-test` атрибуты) | Локаторы вынесены в Page Object — правка в одном месте |
| Нестабильность сети / медленная загрузка | Web-first ассерты Playwright с авто-ожиданием вместо фиксированных задержек |
| Общий тестовый аккаунт может быть занят другими пользователями | Тесты не зависят от состояния, сохраняющегося между запусками |

## 6. Чек-листы

### 6.1 Авторизация

| № | Шаг / проверка | Ожидаемый результат | Статус | Автотест |
|---|---|---|---|---|
| 1 | Вход с валидным логином и паролем | Попадание на inventory.html, заголовок 'Products' виден | ✅ Пройден | `login.spec.ts` |
| 2 | Вход с неверным паролем | Сообщение об ошибке, URL не меняется | ✅ Пройден | `login.spec.ts` |
| 3 | Вход с пустыми полями | Сообщение о необходимости заполнить логин | ⬜ Вручную | — |
| 4 | Вход с заблокированным пользователем (`locked_out_user`) | Сообщение о блокировке аккаунта | ⬜ Вручную | — |

### 6.2 Каталог и корзина

| № | Шаг / проверка | Ожидаемый результат | Статус | Автотест |
|---|---|---|---|---|
| 1 | Добавление товара в корзину | Счётчик = 1, кнопка меняется на 'Remove' | ✅ Пройден | `cart.spec.ts` |
| 2 | Удаление товара из корзины | Счётчик исчезает, кнопка возвращается в 'Add to cart' | ✅ Пройден | `cart.spec.ts` |
| 3 | Добавление нескольких разных товаров | Счётчик равен количеству добавленных товаров | ⬜ Вручную | — |
| 4 | Переход в корзину, проверка списка товаров | Отображаются все добавленные товары с верными названиями/ценами | ✅ Пройден (частично) | `checkout.spec.ts` |

### 6.3 Оформление заказа (Checkout)

| № | Шаг / проверка | Ожидаемый результат | Статус | Автотест |
|---|---|---|---|---|
| 1 | Полный флоу: логин → товар → checkout → подтверждение | Сообщение 'Thank you for your order!' | ✅ Пройден | `checkout.spec.ts` |
| 2 | Переход далее без обязательных полей | Ошибка, переход блокируется | ⬜ Вручную | — |
| 3 | Проверка итоговой суммы (Item total, Tax, Total) | Суммы рассчитаны корректно | ⬜ Вручную | — |
| 4 | Отмена оформления заказа (Cancel) | Возврат в корзину/каталог, заказ не создаётся | ⬜ Вручную | — |

## 7. Матрица трассируемости

| Автотест | Покрывает пункты чек-листа |
|---|---|
| `login.spec.ts` | 6.1 — пп. 1, 2 |
| `cart.spec.ts` | 6.2 — пп. 1, 2 |
| `checkout.spec.ts` | 6.2 — п. 4 (частично); 6.3 — п. 1 |

Пункты со статусом «Вручную» — кандидаты для расширения набора автотестов в следующих итерациях.
